Когда-то давно я написал эту простую настолку на Python, чтобы попрактиковаться в создании интерфейсов на Tkinter и заодно посмотреть, как на практике подключить сторонние языковые модели через библиотеку g4f.

Недавно откопал проект у себя на компьютере и решил залить на GitHub в том виде, в каком он задумывался: как забавный эксперимент по интеграции бесплатного API GPT-4 в обычную десктопную программу.
Суть классическая: поле три на три, игрок выбирает крестик или нолик, а ходы за второго участника делает нейросеть.
Код отправляет текущее состояние матрицы в промпте и просит модель вернуть одну цифру от нуля до восьми, после чего ответ парсится регулярным выражением и отображается на доске.
На интерфейсе есть индикация ожидания хода компьютера, базовая проверка победных комбинаций и кнопка перезапуска игры. Для работы нужен установленный Python и библиотека g4f. 
Запуск стандартный: клонировать репозиторий, поставить зависимость через pip install g4f и выполнить скрипт с кодом приложения.
